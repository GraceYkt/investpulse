# ИнвестПульс — облачный конвейер

Всё крутится на серверах GitHub (бесплатно), компьютер может быть выключен.

## Что делает

Каждый час в :07 (и по кнопке «Run workflow» в GitHub):
1. Тянет портфель из Т-Инвестиции API (до 3 попыток при сбоях шлюза банка);
2. Обновляет котировки MOEX и купоны;
3. Пересобирает подборку топ-10 и глубокую аналитику;
4. Собирает приложение и публикует на GitHub Pages — сайт всегда свежий.

## Настройка (один раз, ~5 минут)

1. Зарегистрируйтесь на https://github.com (любая почта).
2. Создайте репозиторий `investpulse` (можно приватный — Pages работают и с приватными).
3. В настройках репозитория: **Settings → Secrets and variables → Actions → New repository secret**:
   - имя: `TBANK_TOKEN`
   - значение: токен Т-Инвестиции API (только чтение, тот же, что в `broker-token.txt`).
4. **Settings → Pages**: Source = **GitHub Actions**.
5. Залейте содержимое этой папки в репозиторий (любым способом: «upload files» через веб или git).

После первого запуска сайт будет доступен по адресу
`https://<ваш-логин>.github.io/investpulse/`.

## Локальная копия

Локальное приложение (`start-app.bat`) продолжает работать как обычно —
облако её не отменяет, это независимые копии одних данных.
